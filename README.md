Proof-of-concept trade bot for [OpenWF](https://openwf.io). [See the video demo.](https://www.youtube.com/watch?v=18KMWaRnmSA)

## Prerequisites

- A full OpenWF server setup (web, IRC/chat, & HUB)
- A [standalone Pluto install](https://pluto-lang.org/docs/Getting%20Started)

## Setup

```
git clone https://github.com/Sainan/owf-trade-bot
```

## Usage

```
pluto TradeBot.pluto
```
